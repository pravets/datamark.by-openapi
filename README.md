# datamark.by-openapi

Неофициальная OpenAPI-спецификация и Bruno-коллекции для API ГИС «Электронный знак» (datamark.by).

## Отказ от ответственности

Данный проект **не является официальным продуктом** РУП «Издательство «Белбланкавыд». Спецификации и коллекции подготовлены на основе общедоступной документации и не гарантируют полноту, точность или актуальность. Используйте на свой страх и риск. Для получения официальной информации обращайтесь к первоисточнику.

## Первоисточник

Официальная документация API ГИС «Электронный знак»: [datamark.by/dokumenti/](https://datamark.by/dokumenti/)

## Возможности

- **OpenAPI 3.0** спецификация для API маркировки и оборота товаров в формате YAML
- **Bruno-коллекции** с готовыми шаблонами запросов, заголовками, телом и окружениями

## Структура проекта

```
openapi/
  openapi_datamark_v3.yaml  — Спецификация API (96 операций, редакция 4.25)
bruno/
  datamark/                 — Bruno-коллекция API
    environments/           — Окружения (тестовый/промышленный контур)
```

## API

Web-сервис межсистемного взаимодействия ГИС «Электронный знак». Покрывает:

- **Авторизация и делегирование** — авторизация, выход, смена пароля, управление поручениями
- **Каталог товаров** — разделы каталога, добавление/поиск/изменение товаров, инвентаризации
- **Контрагенты** — добавление, получение, список контрагентов
- **Коды и знаки** — регистрация кодов агрегации, структура агрегата, валидация, списание
- **Заказы кодов маркировки** — создание/список/статусы заказов, групповые заказы
- **Отгрузки и приёмка** — отгрузка, приёмка, трансграничные поставки, поставки молочной продукции
- **Отчёты** — 20+ типов отчётов (маркировка, ввод в оборот, смена владельца, агрегирование и др.)
- **Биллинг** — список актов оказанных услуг
- **Вспомогательные методы** — справочники-перечисления, скачивание файлов, список типографий

## Как использовать

### OpenAPI спецификации

Откройте файлы из `openapi/` в любом совместимом инструменте:

- [Swagger Editor](https://editor.swagger.io/)
- [Redoc](https://redocly.com/redoc)
- [Scalar](https://scalar.com/)
- Сгенерируйте клиент через [OpenAPI Generator](https://openapi-generator.tech/)

### Bruno коллекции

1. Установите [Bruno](https://www.usebruno.com/)
2. Откройте коллекцию: `bruno/datamark`
3. Выберите окружение в выпадающем списке
4. Настройте токен аутентификации в `opencollection.yml`
